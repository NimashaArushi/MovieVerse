📋 Level 2: Smart Coding Quiz App — Step-by-Step Plan
🛠️ පියවර 1: Data Setup (ප්‍රශ්න පත්තරේ හදාගනිමු)
මුලින්ම අපි ඇප් එකට අවශ්‍ය ප්‍රශ්න, ඒවායේ තියෙන Options (උත්තර 4), සහ නිවැරදි උත්තරය (correctAnswer) ඇතුළත් Objects Array එකක් කෝඩ් එක ඇතුළේ ලස්සනට හදාගන්නවා.

උදාහරණ: Java Array එකක් ගැන, HTML tag එකක් ගැන ප්‍රශ්න 5ක් වගේ මුලින් දාගන්නවා.

🎯 පියවර 2: Display & Navigation (ප්‍රශ්න එකින් එක පෙන්වමු)
පළමු ඇඩ් කිරීම: එක පාර ප්‍රශ්න ඔක්කොම පෙන්වන්නේ නැතුව, screen එකේ එක පාරකට පෙන්වන්නේ එක ප්‍රශ්නයක් විතරක් වෙන විදිහට හදනවා (currentQuestionIndex state එක පාවිච්චි කරලා).

දෙවන ඇඩ් කිරීම: User උත්තරයක් තෝරලා "Next" බටන් එක ක්ලික් කරාම ඊළඟ ප්‍රශ්නයට smooth විදිහට මාරු වෙන ලොජික් එක හදනවා.

🎨 පියවර 3: Real-Time Score & Feedback (වැරදි/නිවැරදි පාට කරමු)
User කැමති Option එකක් ක්ලික් කරපු ගමන්, ඒක correctAnswer එකට සමානද කියලා අපේ කෝඩ් එකෙන් චෙක් කරනවා.

ලස්සන වැඩක් ඇඩ් කරමු: සමාන නම් ඒ බටන් එක එවලේම කොළ පාට (Green) වෙනවා, වැරදි නම් ක්ලික් කරපු බටන් එක රතු පාට (Red) වෙලා, නිවැරදි උත්තරේ මොකක්ද කියලා කොළ පාටින් හයිලයිට් වෙනවා. ඒ වගේම නිවැරදි නම් Score එකට +1 ක් එකතු වෙනවා.

⏱️ පියවර 4: The Timer (කාලය හරහා සෙල්ලම)
හැම ප්‍රශ්නයකටම තත්පර 15ක හෝ 30ක Count-down Timer එකක් ඇඩ් කරනවා.

ලොජික් එක: තත්පර ගාන 0 වුණොත්, User ට උත්තරයක් තෝරන්න ඉඩ නොදී auto-lock වෙලා "Next" බටන් එක පේන්න ගන්නවා. (මෙතනදී අපි JavaScript setInterval එක React වල පාවිච්චි කරන හැටි ඉගෙන ගන්නවා).

🏆 පියවර 5: Result Dashboard (අවසාන ප්‍රතිඵලය)
ප්‍රශ්න ඔක්කොම ඉවර වුණාම ප්‍රශ්න පෙන්වන එක නතර වෙලා ලස්සන Result Sheet එකක් ලෝඩ් වෙනවා.

ඒකේ ඔයා ගත්ත මුළු ලකුණු ගණන, ඒක ප්‍රතිශතයක් (%) විදිහට (උදා: You Scored 80%), සහ ආයේ මුල ඉඳන් Quiz එක කරන්න "Restart Quiz" බටන් එකක් ඇඩ් කරනවා.
